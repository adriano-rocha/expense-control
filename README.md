# 💰 Expense Control

Aplicação de **controle de despesas** desenvolvida para gerenciar gastos de forma simples e prática.  
O projeto já está disponível online através do link:

🔗 **[Acesse o aplicativo](https://expense-control-five.vercel.app/)**

---

## 📌 Funcionalidades

- ✅ Adicionar e remover despesas.
- ✅ Visualizar lista de transações.
- ✅ Cálculo automático do saldo.
- ✅ Interface simples, responsiva e intuitiva.
- ✅ Deploy realizado na **Vercel**.

---



## 🛠️ Tecnologias utilizadas

- [React.js](https://react.dev/) – construção da interface
- [Vite](https://vitejs.dev/) – ambiente de desenvolvimento
- [CSS](https://developer.mozilla.org/pt-BR/docs/Web/CSS) – estilização
- [Vercel](https://vercel.com/) – deploy e hospedagem
